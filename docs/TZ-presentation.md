## 1. Цель

Коротко и наглядно показать посетителям выставки, что такое META Rooms, какую проблему он решает и как им пользоваться, и привести человека к действию: **отсканировать QR и забронировать аудиторию в демо-версии со своего телефона**.

Метрика успеха: посетитель за 30–60 секунд у стенда понимает суть и открывает демо.

## 2. Аудитория и условия показа

| | |
|---|---|
| Кто смотрит | Студенты, абитуриенты, преподаватели, гости — не технари, читают «на ходу» |

| Как показываем | 1) экран/ноутбук на стенде (ведущий листает или автопоказ); 2) посетитель открывает ту же ссылку по QR у себя на телефоне |

Выводы для дизайна: крупный текст, минимум слов на слайде, высокий контраст, светлая тема, работа без интернета на стенде.

## 3. Формат

- Слайды в браузере, **16:9**, листание стрелками / пробелом / кликом / свайпом.
- Одна статичная страница (HTML + CSS + JS, без сборки), деплой на Vercel.
- 10–12 слайдов, полный проход ≈ 3–4 минуты с ведущим, ≈ 1,5 минуты в автопоказе.

## 5. Визуальный стиль

Берём фирменный стиль самого приложения, чтобы презентация и демо выглядели как одно целое:

- **Цвета:** красный `#d11a2a` → `#8e0e1f` (акцент, градиенты), фон `#fdf9f8`, текст `#16100f`; статусы — зелёный `#1f9d64`, оранжевый `#d98314`, серый `#b9b0af`.
- **Шрифты:** Outfit (заголовки), Rubik (текст). Локальная копия / системный fallback на случай отсутствия сети.
- **Размеры (для экрана 1920×1080):** заголовок ≥ 72px, основной текст ≥ 32px, не более ~25 слов на слайд.
- Мягкие размытые «пятна» фона, скругления 14–20px, как в приложении.
- Анимации: плавное появление элементов (≤ 600 мс), без мельтешения; уважать `prefers-reduced-motion`.

## 6. Функциональные требования

**Обязательно (P0):**
1. Навигация: ← → / пробел / PageUp-Down / клик по краям / свайп на тач-экране.
2. Индикатор прогресса и номер слайда (`5 / 12`).
3. Полноэкранный режим по клавише `F` и кнопке.
4. **Режим автопоказа (киоск)** по клавише `A` или параметру `?auto`: смена слайда каждые ~8 с по кругу; пауза при любом действии пользователя, возобновление через 30 с бездействия.
5. Масштабирование 16:9 под любой экран без обрезки (letterbox).
6. QR-код на демо META Rooms — встроенный SVG (генерируется заранее, не зависит от сети).
7. Работа офлайн: все ресурсы внутри репозитория, внешних запросов нет.

**Желательно (P1):**
8. Мобильная версия при открытии по QR: слайды превращаются в вертикальную ленту с прокруткой.
9. Переключатель языка RU / KZ.
10. Живой мини-демо на слайде 5: клик по аудитории на плане меняет её статус на «моя бронь» с тостом.
11. Прямая ссылка на слайд через `#5`.

**Не делаем:** бэкенд, аналитику, редактор слайдов.
